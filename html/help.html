Chrome Extension · v2

BETTER AutoLaTeX

Overleaf-style LaTeX editing and PDF rendering inside Google Docs — with split-view preview, live syntax highlighting, and hotkey-driven rendering.

Buttons & shortcuts

What each control does

Open the popup from the extension icon in Chrome's toolbar. Hotkeys are active inside the Google Docs editor and work on Mac with ⌘ in place of Ctrl.

⚡
Recommended

Render PDF — Ctrl+Shift+Z

Compiles your document and shows the PDF in the split panel — or a new tab, depending on the Render to mode. If compilation fails, the error log appears in the panel instead.

⬇

Download PDF — Ctrl+Shift+X

Compiles and saves the PDF as Your Doc Title.pdf through Chrome's downloads system.

🎨

Format Document — Ctrl+Shift+F

Applies Overleaf-style syntax highlighting once across the whole doc: commands blue, math content green, math commands purple, environment names teal, comments green. Runs through a shared backend with no setup — the first use will prompt you to authorize it for your own Google account.

⟳
Auto

Auto-format — Ctrl+Shift+F × 2

The popup toggle (or a double-tap of the format hotkey) keeps highlighting live, reformatting only the paragraphs that change as you type.

▣

Render to — Split View / New Tab

Chooses where rendered PDFs open: the in-page split panel or a separate browser tab. The choice is remembered.

⚙

Settings

Set the document class, the font family and size auto-format applies, and the six syntax highlighting colors. Preferences save automatically.

📝

Edit Preamble

Edit the LaTeX preamble — add packages, custom commands, or theorem styles, and upload .sty files that ride along with every render.

⏻

Enable / disable

The header toggle turns the extension on or off without removing it from Chrome.

Split view

PDF and error preview inside Google Docs

The split panel opens whenever you render — whether compilation succeeded or failed.

▣

Side-by-side editing

The panel occupies 50% of the browser window by default, with the Google Docs editor on the left. The Docs toolbar and document layout reflow automatically to fit the remaining space.

↔

Resizable — width is remembered

Drag the left edge of the panel to resize it. The width you settle on is saved to extension storage and restored on every subsequent render, even across browser restarts.

⚠

Compilation errors in the panel

If LaTeX compilation fails, the error log is shown in the split panel at your saved width. No separate tab opens and you stay in the document.
