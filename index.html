Chrome extension

BETTER AutoLaTeX

Render Google Docs as LaTeX PDFs, preserve rich text and tables, and keep your workflow inside the document.

Download extension (.zip) Installation guide

Get started

Install in Chrome

BETTER AutoLaTeX is installed as an unpacked Chrome extension. Keep the extracted folder somewhere you will not move or delete.

Download and unzip

Download the ZIP above, then extract it. Select the extracted folder that contains manifest.json.

Open Extensions

Navigate to chrome://extensions and turn on Developer mode.

Load unpacked

Choose Load unpacked, then select the extracted extension folder.

Approve access

Open the authorization link below once, approve the Google prompt, then return to your Google Doc.

Required once

Approve the formatter

The formatter needs your permission to read and apply document formatting. Open this link while signed into the Google account you use for Docs:

Approve Google Apps Script access

Use it

Render from Google Docs

Open Better AutoLaTeX

In a Google Doc, use the Better AutoLaTeX menu beside the standard Docs menus.

Choose a destination

Use Render to (Split Screen) or switch to New Tab before rendering.

Render or download

Choose Render PDF, Download PDF, or use Ctrl + Shift + Z and Ctrl + Shift + X.
